Accessibility statement

About this site

Barrier/Fix was built to show, not just tell, why accessibility matters. Flip a switch, feel the difference. It uses only HTML and CSS, with no JavaScript.

0 lines of JavaScript. Every switch on this site is HTML and CSS.

How it was built

How this site was built

  • Semantic HTML: <header>, <nav>, <main>, <section>, <article> and <footer> on every page.
  • One external stylesheet shared by all eight pages.
  • A skip link, visible keyboard focus and a consistent menu.
  • The Barrier/Fixed switch is a real checkbox with a label, so it works with a keyboard and screen readers.
  • Text in rem units, a responsive layout, and animations that stop if you prefer reduced motion.
  • A real video with a <track> caption file and a full transcript.

Known limits

The weather video on the Hearing page is a real <video> with sound and a real WebVTT caption file. The presenter's voice is computer-generated, and the news site and forecast are made up.

In Barrier mode the captions are hidden with CSS to show the problem. Your browser's own CC button may still appear.

The colour blindness map is a rough simulation and not exact for every type of colour vision.
